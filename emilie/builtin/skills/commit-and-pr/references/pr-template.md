# PR description template

## Summary
1-3 sentences: what changes and why (link the issue).

## Changes
- bullet per logical change, user-visible effect first

## Testing
Commands run and results; manual steps; what is NOT tested.

## Risk and rollout
Breaking changes, migrations, flags, performance, how to roll back.

## Notes for reviewers
Where to start reading, tricky parts, follow-ups left out on purpose.

Keep the title under 70 chars, Conventional style. Screenshots for UI changes. Mark drafts as draft.
